
# 🌍 Multilingual Alphabet Counter

A simple and interactive web application built using HTML, CSS, and JavaScript. It allows users to increase and decrease letters in three different languages: English, Telugu, and Hindi.

## 🚀 Features

- English Alphabet (A - Z)
- Telugu Alphabet (అచ్చులు + హల్లులు)
- Hindi Alphabet (स्वर + व्यंजन)
- Separate cards for each language
- Increase letter functionality
- Decrease letter functionality
- Reset button for each language
- Independent counters
- Responsive design for mobile and desktop
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three files are in the same folder.
4. Open index.html in your browser.
5. Start using the alphabet counters.

## 🎯 How It Works

### English Card
- Increase: Moves to the next English letter.
- Decrease: Moves to the previous English letter.
- Reset: Returns to A.

### Telugu Card
- Increase: Moves to the next Telugu letter.
- Decrease: Moves to the previous Telugu letter.
- Reset: Returns to అ.

### Hindi Card
- Increase: Moves to the next Hindi letter.
- Decrease: Moves to the previous Hindi letter.
- Reset: Returns to अ.
